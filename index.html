04 / Engineering

What was actually engineered.

A recruiter should be able to understand the engineering scope without reading the entire repository.

01 / REALTIME

Event-driven security workflow

Connects telemetry ingestion, detection, correlation, alerting and realtime analyst experiences instead of treating security as a static dashboard.

02 / AGENTS

Agentic investigation

AI agents work with structured alert context and typed tools for evidence gathering, threat intelligence and investigation tasks.

03 / GOVERNANCE

Human-in-the-loop response

High-impact response remains behind authorization and human approval rather than silently executing autonomous actions.

04 / AUDIT

Investigation Ledger

Investigation activity, prompts, tool calls, citations, verdicts and token cost can be recorded for review and auditability.

05 / SECURITY

Detection + threat intelligence

Repository capabilities include executable detection rules, alert correlation, MITRE ATT&CK references and CISA KEV threat intelligence.

06 / FULL STACK

Product engineering

Frontend, realtime services, APIs, data stores, AI services, testing, deployment and operational tooling are part of the project surface.
